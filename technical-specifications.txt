# Техническое задание (ТЗ)

## 1. Цель проекта

Создание локального веб‑сайта для обмена аудио и видео файлами между компьютерами внутри одной сети без доступа к интернету.

Система должна обеспечивать:

* загрузку файлов на сервер
* просмотр и прослушивание медиа
* скачивание файлов
* управление доступом пользователей

## 2. Пользователи и роли

### 2.1 Роли

1. **Администратор**

   * управление пользователями
   * удаление любых файлов
   * просмотр логов
   * настройка системы

2. **Пользователь**

   * загрузка аудио и видео
   * просмотр и скачивание файлов
   * удаление только своих файлов

## 3. Функциональные требования

### 3.1 Авторизация

* Авторизация по логину и паролю
* Хранение паролей в зашифрованном виде
* Автоматический выход при бездействии

### 3.2 Работа с файлами

**Загрузка:**

* Поддержка форматов:

  * Видео: mp4, mkv, avi
  * Аудио: mp3, wav, flac
* Ограничение размера файла (настраиваемое)
* Отображение прогресса загрузки

**Просмотр:**

* Встроенный HTML5‑плеер
* Потоковое воспроизведение без скачивания

**Скачивание:**

* Скачивание оригинального файла

### 3.3 Категории и структура

* Разделы:

  * Видео
  * Аудио
* Возможность создания папок
* Сортировка по:

  * дате
  * размеру
  * названию

### 3.4 Поиск

* Поиск по названию файла
* Фильтр по типу (аудио/видео)

## Результат

Готовый локальный веб‑сайт для обмена аудио и видео файлами, работающий в закрытой сети из 1 сервера и 10 компьютеров.
